🛒 Amazon Homepage Clone

This is a static clone of the Amazon home page, built using HTML5 and CSS3. It replicates the layout and design of the real Amazon website including the navbar, hero section, product boxes, and footer, providing a hands-on project to practice responsive design and UI layout techniques.

📌 Features

Responsive top navigation bar with logo, search box, and cart
Hero section with promotional banner
Interactive shopping boxes displaying various categories
Fully designed multi-column footer with links
Uses Font Awesome for icons
Clean layout mimicking Amazon's aesthetic

🛠️ Technologies Used

HTML5
CSS3
Font Awesome (CDN)

🚀 How to Use

Clone the repository or download the files:

> git clone https://github.com/your-username/amazon-homepage-clone.git


Open the project:

Make sure index.html and index.css are in the same directory.
Double-click index.html to open it in your browser.
Make sure to have these image files in your project folder:
amazon_logo.png
hero_image.jpg
box1_image.jpg to box8_image.jpg
